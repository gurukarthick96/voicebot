# VoiceBot

This repository contains a suite of **AI-powered conversational systems**, including:

- **Bot Action Server** built with **Rasa SDK**, integrated with **LLM** and **Vector DB** for intelligent action handling.
- **Bot Voice Server** built with **FastAPI**, supporting **Speech-to-Text (STT)** and **Text-to-Speech (TTS)**, along with a simple **Jinja2-based UI**.
- **Conversational Bot Server** built with **Rasa**, a leading framework for building dialogue systems.

Each folder contains its own `README.md` with detailed setup instructions, usage, and examples. Please refer to the README in the respective folder for more information:

- [`buy-bot-action-server`](buy-bot-action-server/README.md)  
- [`buy-bot-voice-server`](buy-bot-voice-server/README.md)  
- [`buy-bot-server`](buy-bot-server/README.md)
